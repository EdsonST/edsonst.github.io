Política de Privacidade — Extratus

Última atualização: Agosto de 2026

O Extratus respeita a privacidade dos seus usuários. Esta política descreve como tratamos (ou não tratamos) seus dados.

1. Resumo

O Extratus NÃO coleta, NÃO armazena e NÃO transmite dados pessoais ou financeiros para servidores externos. Todos os dados ficam exclusivamente no dispositivo do usuário.

2. Dados Armazenados Localmente

O App armazena no dispositivo do usuário:

  • Lançamentos financeiros (receitas, despesas)
  • Informações de cartões de crédito (nome, limites, faturas)
  • Categorias personalizadas
  • Nome do perfil (opcional)
  • Preferências do aplicativo

Esses dados são armazenados usando AsyncStorage do dispositivo e nunca são enviados para servidores externos.

3. Dados que NÃO Coletamos

  • Não coletamos dados bancários reais (senhas, tokens, números de conta)
  • Não coletamos localização
  • Não coletamos contatos
  • Não coletamos fotos ou mídias (exceto se futuramente o usuário optar por anexar comprovantes)
  • Não coletamos histórico de navegação
  • Não coletamos identificadores de dispositivo para rastreamento

4. Compartilhamento de Dados

O Extratus NÃO compartilha dados do usuário com terceiros, parceiros comerciais, redes de publicidade ou qualquer outra entidade.

A única forma de dados saírem do dispositivo é se o próprio usuário utilizar a função "Exportar Dados", que gera um arquivo JSON sob total controle do usuário.

5. Publicidade

  • A versão gratuita pode exibir anúncios fornecidos pelo Google AdMob.
  • O Google AdMob pode coletar identificadores anônimos de publicidade do dispositivo conforme sua própria política de privacidade (https://policies.google.com/privacy).
  • O Extratus em si NÃO envia dados financeiros do usuário para redes de publicidade.
  • Usuários da versão premium não visualizam anúncios.

6. Segurança

  • Os dados são protegidos pela autenticação biométrica do dispositivo (fingerprint/face).
  • O Extratus não implementa criptografia adicional sobre o AsyncStorage nativo.
  • A segurança dos dados depende das configurações de segurança do próprio dispositivo do usuário (PIN, biometria, criptografia de disco).

7. Exclusão de Dados

O usuário pode excluir todos os seus dados a qualquer momento através de:

  • Configurações → Limpar Dados (dentro do app)
  • Desinstalação do aplicativo (remove todos os dados locais)

8. Crianças

O Extratus não é direcionado a menores de 18 anos. Não coletamos conscientemente informações de menores. Se tomarmos conhecimento de que dados de menor foram armazenados, providenciaremos a exclusão.

9. Alterações na Política

Podemos atualizar esta Política de Privacidade periodicamente. A versão mais recente estará sempre disponível no aplicativo e nesta página. O uso continuado após alterações constitui aceitação.

10. Seus Direitos (LGPD)

Conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Confirmação da existência de tratamento de dados
  • Acesso aos dados (disponível via função Exportar)
  • Correção de dados (disponível via função Editar)
  • Eliminação de dados (disponível via função Limpar Dados)
  • Portabilidade (disponível via função Exportar JSON)

Como o Extratus opera em modo offline-first sem coleta de dados em servidores, a maioria desses direitos é exercida diretamente pelo usuário dentro do aplicativo.

11. Contato

Para questões sobre privacidade:

  • Site: página do Extratus no site da ES Studio
  • Email: es.suporte.app@gmail.com

12. Consentimento

Ao utilizar o Extratus, você declara estar ciente e de acordo com esta Política de Privacidade.
