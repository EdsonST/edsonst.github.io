Como funciona

Cada pista é um pedaço de código

No primeiro caso, alguém copiou o código-fonte de uma empresa às 23h. O registro do servidor mostra este trecho. O que ele imprime?

Antes de cada desafio, o jogo ensina o conceito. Se errar, explica por quê. Se travar, oferece dicas em quatro níveis. Ninguém precisa saber programar para começar.

// registro_acesso.js let cracha = "NX-0417"; let horaAcesso = 23; let origem = "rede externa"; console.log(horaAcesso, origem); > ?
